# AIOverlayAssistant

Dự án Android mẫu để build APK debug bằng GitHub Actions.

## Tạo APK
1. Đưa toàn bộ nội dung ZIP lên thư mục gốc repository GitHub (không upload ZIP như một file duy nhất).
2. Mở tab **Actions**.
3. Chọn workflow **Build Android APK** và nhấn **Run workflow** nếu workflow chưa tự chạy.
4. Mở lần chạy thành công, tải artifact **AIOverlayAssistant-debug-apk**.

## Lưu ý
Đây là bộ khung chạy thử: có màn hình chính và nút nổi overlay cơ bản. Chưa tích hợp AI thật, dịch vụ email/OTP hay tự động điều khiển ứng dụng.
